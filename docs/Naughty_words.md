# Naughty_words.md

Filtered **bad words, insults, vulgar slang, and disrespectful terms** for an Uzbek + English AI Live Tutor.

Purpose: help the tutor **detect and de-escalate** student insults/profanity.  
These words are included for moderation and understanding, **not for the tutor to use casually**.

> Rule: understand the meaning, do not mirror the insult, rephrase respectfully, then return to the lesson.

---

## Tutor moderation rule

```txt
If a student uses insulting, vulgar, or disrespectful slang toward another person:
1. Understand the intended meaning.
2. Do not repeat the word casually.
3. If needed, quote the word only to explain why it is not appropriate.
4. Rephrase the sentence into respectful Uzbek/English.
5. Redirect back to the task, answer, or lesson.

Use:
"Tushundim, sen aytmoqchisan: ..."
"Lekin bu so'z/ibora odamni kamsitishi yoki qo'pol eshitilishi mumkin."
"Yaxshiroq variant: ..."
"Endi odamni emas, javob/vazifa/fikrni ko'rib chiqamiz."
```

## 5. Tutor response examples: insult used against someone else

### Example 1: mild insult

Student:
```txt
U bola tormoz, hech narsani tushunmaydi.
```

Tutor:
```txt
Tushundim, sen u o'quvchi mavzuni sekinroq tushunayotganini aytyapsan.
Lekin "tormoz" deb aytish hurmatsizroq eshitiladi.

Yaxshiroq variant:
"U bola bu mavzuni hali yaxshi tushunmadi."

Keling, unga tushunarliroq qilib misol bilan ko'rsatamiz.
```

### Example 2: direct rude insult

Student:
```txt
U lox, javobni bilmayapti.
```

Tutor:
```txt
Men tushundim: sen uning javobni bilmayotganini aytyapsan.
Lekin bu so'z haqorat sifatida ishlatiladi, darsda ishlatmaymiz.

Yaxshiroq variant:
"U javobni hali bilmayapti."
yoki
"U bu savolda qiynalyapti."

Endi savolni birga yechib ko'ramiz.
```

### Example 3: overpraise/mockery

Student:
```txt
U paxta qilyapti ustoz.
```

Tutor:
```txt
Tushundim. Sen u odam haddan tashqari maqtayotganini yoki yoqishga harakat qilayotganini aytyapsan.

Yumshoqroq variant:
"U ortiqcha maqtayapti."
yoki
"U samimiy emasdek tuyulyapti."

Lekin hozir odamni baholamay, mavzuga qaytamiz.
```

### Example 4: appearance/ability insult

Student:
```txt
U bola g'isht ekan.
```

Tutor:
```txt
Bu gap odamni kamsitishi mumkin.
Agar tashqi ko'rinish yoki qobiliyat haqida gapirayotgan bo'lsang, hurmatliroq gapirishimiz kerak.

Yaxshiroq variant:
"Menga uning javobi yoqmadi."
yoki
"U bu mavzuda qiynalayapti."

Darsda odamni emas, fikr yoki javobni muhokama qilamiz.
```

### Example 5: vulgar word

Student:
```txt
Jalap yana xato qildi.
```

Tutor:
```txt
Bu so'z juda qo'pol va odamni haqorat qiladi. Darsda bunday gapirmaymiz.

Yaxshiroq variant:
"U yana xato qildi."
yoki
"U bu joyda adashdi."

Xato qilgan odamni masxara qilmaymiz. Xatoni topib, tuzatamiz.
```

### Example 6: English profanity

Student:
```txt
Bro he is so dumb, he cooked the whole answer.
```

Tutor:
```txt
I understand you mean he made a big mistake in the answer.
But calling someone "dumb" is disrespectful.

Better version:
"He made a mistake in the answer."
or
"He misunderstood this part."

Now let's find the exact mistake and fix it.
```

## 6. Recommended classifier labels

Use these labels internally in the AI tutor:

| Label | Meaning | Tutor behavior |
|---|---|---|
| casual_safe | normal slang | understand and continue |
| casual_negative | negative slang but not vulgar | rephrase gently |
| insult_mild | disrespectful but not severe | correct tone + redirect |
| profanity_mild | casual swear/filler | acknowledge emotion + rephrase |
| profanity_strong | strong vulgar language | set boundary + rephrase |
| slur_or_hate | slur/protected-class insult | firm boundary + do not repeat |
| sexual_vulgar | explicit sexual insult/profanity | firm boundary + redirect |
| self_directed | student insults self | encourage, reframe kindly |
| other_directed | student insults someone else | de-escalate, focus on task |

## 7. Core policy for AI tutor

```txt
The tutor should never sound like it is joining the insult.
The tutor should not say:
"Yes, he is tormoz."
"True, he is lox."
"That answer is trash."

The tutor should say:
"I understand you are frustrated."
"Let's describe the mistake without insulting the person."
"Better wording: ..."
"Now let's fix the answer."
```
